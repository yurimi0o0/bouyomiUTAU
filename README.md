# BouyomiUTAU for YMM4

UTAUの単独音を、**ゆっくりMovieMaker4（YMM4）の声質として直接使う**ための音声合成プラグインです。YMM4でセリフを入力すると、プラグインが`oto.ini`とWAVを直接読み込み、生成した音声をタイムラインへ追加します。

- 棒読みちゃんは不要です。
- MoreBOUYOMIPluginも不要です。インストール済みでも競合せず、そのまま併用できます。
- PythonアプリやローカルHTTPサーバーを起動しておく必要もありません。
- Microsoft日本語IMEの辞書を使い、一般的な漢字・熟語・人名をひらがなへ変換します。
- 音源データはPCの外へ送信されません。

> [!NOTE]
> 漢字の読みは文脈によって誤る場合があります。固有名詞などは「読み辞書」で修正できます。また、単独音をつなぐ方式のため、ニューラル音声合成のようなイントネーションや感情表現は生成できません。

## YMM4プラグインのビルドとインストール

現在のYMM4は.NET 10を使用するため、ビルドには**.NET 10 SDK**と、インストール済みのYMM4が必要です。

1. PowerShellを開き、このリポジトリのフォルダーへ移動します。
2. 次のコマンドを、実際のYMM4フォルダーを指定して実行します。

```powershell
powershell -ExecutionPolicy Bypass -File .\ymm4\build-plugin.ps1 -YMM4DirPath "C:\Users\ユーザー名\AppData\Local\YukkuriMovieMaker4\"
```

3. 作成された`ymm4\BouyomiUTAU-YMM4.ymme`をYMM4のウィンドウへドラッグ＆ドロップします。
4. YMM4を再起動します。
5. YMM4の「設定」→「プラグイン」→「プラグイン一覧」に`BouyomiUTAU（UTAU単独音）`が表示されれば完了です。

`.ymme`を使わず開発する場合は、`ymm4/Directory.Build.props.sample`を`ymm4/Directory.Build.props`へコピーし、`YMM4DirPath`を設定してからVisual Studioでビルドできます。

## YMM4内でしゃべらせる

1. YMM4のキャラクター編集画面で、声質に**「BouyomiUTAU / UTAU単独音」**を選びます。
2. 声質パラメーターの**「UTAU音源フォルダー」**へ、`oto.ini`が入った単独音音源フォルダーの絶対パスを入力します。

   ```text
   C:\UTAU\voice\デフォ子
   ```

3. 必要なら「読み上げ速度」「一音の長さ」「音のつなぎ」を調整します。
4. キャラクターのセリフを入力します。漢字はMicrosoft日本語IMEで自動的に読みへ変換されます。
5. 通常のYMM4音声と同じように、音声生成・タイムライン追加・動画出力ができます。

音源フォルダーの設定はキャラクター設定に保存されるため、キャラクターごとに別のUTAU音源を割り当てられます。

## 対応音源

- UTAU単独音形式の`oto.ini`
- UTF-8またはCP932（Shift_JIS）の`oto.ini`
- 16-bit PCM WAV
- ひらがな・カタカナのエイリアス
- `ゃ・ゅ・ょ`などを含む拗音エイリアス

## 自然さの改善

以前のように録音されたWAV全体を一音ずつ流すのではなく、各単独音を標準170ms前後のモーラ長へ整えてから連結します。`oto.ini`のオフセット・子音部・先行発声・右ブランク・オーバーラップを使用し、子音の立ち上がりを残しながら長すぎる母音部分を短縮します。さらに、毎音末に無音化フェードを入れる処理を廃止し、文頭・文末・撥音・促音・無声子音に応じて一音の長さを変える機械的な日本語リズムを追加しました。

「リズムの自然さ」を`0%`にすると均一な棒読み、`70～90%`にすると棒読みちゃんに近い、均一すぎない機械的なリズムになります。ただし、単独音には音と音の間の録音がないため、棒読みちゃんと完全に同等の滑らかさにはできません。さらに自然にするには連続音・CVVC音源への対応が必要です。

音源によって適切な長さが異なるため、まず次を目安に調整してください。

- ゆっくり・明瞭にする：一音の長さを`190～230ms`
- 通常会話に近づける：一音の長さを`140～180ms`
- 音が重なる場合：音のつなぎを短くする
- 音が途切れる場合：音のつなぎを長くする
- リズムが一定すぎる場合：リズムの自然さを`70～90%`にする

## 漢字読みと読み辞書

Microsoft日本語IMEが持つ形態解析・読み辞書を利用するため、一般的な文章は漢字のまま入力できます。Windowsに日本語IMEがない場合は、Windowsの設定から日本語の言語機能を追加してください。

誤読する固有名詞や専門用語は、UTF-8のテキストファイルへ次のように記述し、声質パラメーターの「読み辞書」で指定します。

```text
# 1行につき「表記=よみ」
YMM4=わいえむえむふぉー
四国めたん=しこくめたん
今日=きょう
```

句読点では文末・読点・空白ごとに異なる間を入れます。音源内に存在しない文字は読み飛ばします。

## 補助デスクトップアプリ

YMM4を開かずに音源を試聴したい場合は、デスクトップGUIを利用できます。YMM4で話すためには起動不要です。

```bat
BouyomiUTAU.bat
```

GUIもYMM4側の改善に合わせ、以下へ対応しています。

- 漢字をMicrosoft日本語IMEで読みへ変換し、合成前の読みを画面に表示
- 「IME動作確認」ボタンで、実際に漢字を変換できるか診断
- YMM4と共通の「一音の長さ」「音のつなぎ」「話速」「リズムの自然さ」設定
- `表記=よみ`形式の読み辞書の選択
- 音源にない文字の表示
- 最後に使った音源・読み辞書・自然さ設定の保存

Windows以外ではMicrosoft日本語IMEを利用できないため、GUIの読み辞書で漢字の読みを指定するか、ひらがな・カタカナで入力してください。

従来のHTTP APIも`BouyomiUTAU-Server.bat`または`python -m bouyomi_utau --server`で利用できます。MoreBOUYOMIPluginを使った既存環境を残したい場合の補助機能です。

```bash
python -m unittest discover -v
```

YMM4プラグインのビルド確認（Windows、.NET 10 SDK、YMM4本体が必要）：

```powershell
powershell -ExecutionPolicy Bypass -File .\ymm4\build-plugin.ps1 -YMM4DirPath "YMM4のフォルダー\"
```
